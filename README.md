One line, at most 120 characters: the funniest voicemail greeting a cat
would record. See the contest at
https://make.fun/bounty/u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443.

`main.ts` (Node 22) writes the greeting to `/output/entry.txt`.
`versions.md` holds the three candidate greetings considered for this entry.
